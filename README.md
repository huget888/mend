mend is one patch tool for every AI edit format: a Node 22 CLI that reads unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls to one written specification, finds the lines each edit names at the first of three matching tiers, and changes every file or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
